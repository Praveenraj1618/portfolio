# Praveen Raj — AI/ML Portfolio

Recruiter-focused portfolio featuring Legal AI, Virtual Try-On, AgroVision, Company Lens, Integrated Track Monitoring System (ITMS), Speech to Sign, AI & Workflow Automation, and WasteZero.

## Run locally

No installation or build is required. From the repository root:

```bash
python3 -m http.server 4173 --directory dist
```

Open http://localhost:4173.

## Files

- `dist/index.html`: profile, education, experience, contact links, and project summaries.
- `dist/style.css`: responsive AI/ML visual theme.
- `dist/script.js`: project filtering, case-study dialogs, and interactive project walkthroughs.
- `dist/assets/favicon.svg`: portfolio icon.
- `.openai/hosting.json`: existing Sites project identity and static serving directory.

## Project evidence

Case studies separate the problem, approach, stack, evidence, and outcome. Recorded benchmarks are qualified by their original scope; interactive walkthroughs are illustrative and do not run project models.

AI & Workflow Automation describes résumé-documented work at Marobust Tech and Solutions, including n8n workflows, service integrations, hospital booking, and Telegram interactions. The hospital repository is related implementation context, not the source of private client workflows. No résumé file or client credentials are included.

ITMS uses a schematic, with no photograph.

## Privacy and deployment

Keep this repository and the deployed portfolio private unless the owner explicitly approves public release. The existing Sites deployment enforces owner-only authentication. Static files served locally or elsewhere do not provide that authentication themselves; `robots.txt` and `noindex` are only crawler hints.

No automatic publishing workflow is configured.
